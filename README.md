# 视频墙 Video Wall

**简体中文** | [English](./README_EN.md)

基于 Next.js 构建的多视频矩阵展示页面：自定义视频个数（1–12）与任意行列矩阵，批量上传视频并为每个视频填写标题介绍，一键「同时播放」让全部视频同步起播。所有数据持久化保存在服务端，刷新页面或更换设备均不丢失。

## 功能特性

- **动态数量与矩阵**：视频位数量 1–12 任意切换，支持任意「行 × 列」组合；质数数量自动提供补位矩阵选项；单视频时自动满幅展示。
- **多种上传方式**：点击空位选择文件、整页拖拽导入、一键多选导入；文件数量超过当前位数时自动扩位并匹配矩阵。
- **标题介绍**：每个视频下方配备独立标题框，自动增高、防抖保存、刷新不丢失。
- **同时播放**：所有视频统一回到开头后同步起播；提供全局静音与循环开关，状态自动记忆。
- **服务端持久化**：视频文件与清单保存在服务器；文件流支持 HTTP Range 分段播放，可自由拖动进度条。
- **交互细节**：缩减位数二次确认、替换上传自动清理旧文件、提示信息防叠加、布局切换零抖动。

## 快速开始

环境要求：Node.js ≥ 20.9 或 Bun ≥ 1.1。

```bash
# 安装依赖
bun install          # 或 npm install

# 开发模式（监听 http://localhost:3000）
bun run dev          # 或 npm run dev

# 生产构建与启动
bun run build
bun run start
```

关闭方式：前台运行的进程在终端按 Ctrl + C；后台进程执行 `lsof -ti:3000 | xargs kill` 释放 3000 端口。

## 单页精简版（免部署）

如果只想快速播放几个视频、不想安装任何环境，可以直接使用仓库根目录的 [`standalone.html`](./standalone.html)。这是一个零依赖的单文件页面，下载后用浏览器打开即可使用：

- 将 `standalone.html` 与 6 个视频放在同一目录，视频按 `video1.mp4` 至 `video6.mp4` 命名；
- 双击用浏览器打开，即可获得 3 × 2 视频矩阵、同步起播、从头重播、全局循环开关与标题编辑（标题保存在浏览器本地，需浏览器允许 localStorage）；
- 无需安装依赖、无需启动服务，适合临时演示与快速查看。

需要自定义视频数量与矩阵、服务端持久化、跨设备访问时，请使用上方的完整版本。

## 技术栈

Next.js 16（App Router）· React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · sonner · 文件系统存储（无需数据库）

## 注意事项

- 本项目**未内置任何鉴权机制**，所有访问者均可上传与删除内容。部署到公网时，请在反向代理层配置 Basic Auth、IP 白名单等访问控制。
- 上传限制：单文件不超过 200MB，支持 MP4 / MOV / WebM 等常见视频格式，视频位最多 12 个。
- 全部运行数据保存在 `data/` 目录（已加入 .gitignore），复制该目录即可完成整体备份。
- 仓库中的 `prisma/` 与 `.env` 为脚手架遗留文件，本项目不使用数据库，可安全忽略。
