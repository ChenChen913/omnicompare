# OmniCompare（灵动对比）

**简体中文** | [English](./README_EN.md)

基于 Next.js 构建的多内容并行对比工作台（AI Output Comparison Tool）：把多个模型 / 工具对同一任务产出的内容——视频、HTML 页面——放进同一个矩阵中并行展示，用于视觉对比与评估。项目由「视频墙 Video Wall」演进而来，继承了其服务端持久化、矩阵布局与批量播放能力，并扩展为多类型内容工作台。所有数据持久化保存在服务端，刷新页面或更换设备均不丢失。

## 功能特性

- **双类型内容**：视频（MP4 / MOV / WebM 等常见格式）与单文件自包含 HTML 页面放进同一矩阵并行对比，HTML 上传即运行。
- **灵活矩阵**：内容位 1–12 个，行 × 列任意组合；导入超出自动扩位，单内容自动满幅。
- **多项目管理**：多个项目内容与布局互相隔离，按「进行中 / 草稿 / 已归档」分组，支持改名、状态调整与删除。
- **多样导入**：点击空位选择、整页拖拽、一键多选三种方式。
- **顶栏自动适配**：视频项目自带播放控件（循环 / 静音 / 倍速），纯 HTML 项目主动作自动变为「刷新全部」；卡片比例（原始 / 16:9 / 9:16 / 1:1）与标题 / 属性显隐一键切换。
- **独立标题框**：每个内容下方可填标题（通常为模型名），防抖保存、刷新不丢失。
- **双模式与双主题**：Studio / Focus 一键切换，Focus 只留内容矩阵适合演示录屏；暗 / 亮主题一键切换。
- **安全沙箱**：HTML 经 iframe sandbox 与服务端安全响应头双重隔离，可放心展示任意模型产出的页面。
- **服务端持久化**：内容与设置按项目保存在服务器，跨设备同步不丢失；视频流支持 HTTP Range 分段播放。

## 快速开始

环境要求：Node.js ≥ 20.9 或 Bun ≥ 1.1。

```bash
# 安装依赖
bun install          # 或 npm install

# 开发模式（监听 http://localhost:3000）
bun run dev          # 或 npm run dev

# 生产构建与启动
bun run build
bun run start
```

关闭方式：前台运行的进程在终端按 Ctrl + C；后台进程执行 `lsof -ti:3000 | xargs kill` 释放 3000 端口。

## 单页精简版（免部署）

如果只想快速播放几个视频、不想安装任何环境，可以直接使用仓库根目录的 [`standalone.html`](./standalone.html)。这是一个零依赖的单文件页面，下载后用浏览器打开即可使用：

- 将 `standalone.html` 与 6 个视频放在同一目录，视频按 `video1.mp4` 至 `video6.mp4` 命名；
- 双击用浏览器打开，即可获得 3 × 2 视频矩阵、同步起播、从头重播、全局循环开关与标题编辑（标题保存在浏览器本地，需浏览器允许 localStorage）；
- 无需安装依赖、无需启动服务，适合临时演示与快速查看。

需要多类型内容、服务端持久化、跨设备访问时，请使用上方的完整版本。

## 技术栈

Next.js 16（App Router）· React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · sonner · 文件系统存储（无需数据库）

## 注意事项

- 本项目**未内置任何鉴权机制**，所有访问者均可上传与删除内容。部署到公网时，请在反向代理层配置 Basic Auth、IP 白名单等访问控制。
- 上传限制：视频单文件不超过 200MB，支持 MP4 / MOV / WebM 等常见格式；HTML 限单文件自包含页面且不超过 10MB；内容位最多 12 个。
- HTML 页面仅支持**单文件自包含**（内联 CSS/JS）；依赖本地同目录 CSS / JS / 图片的页面暂不支持，外链 CDN 资源可以正常加载。
- 全部运行数据保存在 `data/` 目录（已加入 .gitignore），复制该目录即可完成整体备份。
- 仓库中的 `prisma/` 与 `.env` 为脚手架遗留文件，本项目不使用数据库，可安全忽略。
